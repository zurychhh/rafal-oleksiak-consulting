Motion

Motion only when it carries narrative. The canon: pale fields enter every 0.05s for 2.3s, then amber every 0.075s, each growing to 155% and settling back. Ends around 4.6s. One pass, fired at 20% of the viewport, never a loop.

  1. The end state is the DOM default — animate from empty to default, never the reverse.
  2. prefers-reduced-motion jumps straight to the end state.
  3. The QA gate must never catch the screen mid-motion.
