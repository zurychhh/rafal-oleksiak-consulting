# REVIEW — werdykty recenzenta całości

Pisze wyłącznie Recenzent całości, po każdym cyklu budujących. Najnowszy wpis
na górze, maksimum 30 wpisów (starsze scalaj w jedno zdanie na dzień).
Czytają: budujący (pole NASTĘPNY BIEG), promotor (pole KANDYDAT), strateg
(pole DLA STRATEGA).

## Format wpisu

```
## <data i godzina UTC> — cykl <N>
Werdykt: POPRAWA / BEZ ZMIANY / REGRESJA (osobno: narzędzie, Claude Design, produkcja)
Zgodność z USP v<N>: <jedno zdanie>
Uczciwość pomiaru: <czy któryś budujący raportował sukces, którego nie widać>
KANDYDAT: <URL artefaktu z Claude Design + nazwa strony, albo „brak”>
NARZĘDZIE DO PROMOCJI: TAK/NIE (patch_run z loop-spec)
NASTĘPNY BIEG — narzędzie: <jedna mierzalna rzecz>
NASTĘPNY BIEG — Claude Design: <jedna mierzalna rzecz>
DLA STRATEGA: <co z efektów podważa albo wzmacnia obecne USP>
CZEGO NIE RUSZAĆ: <lista>
```
